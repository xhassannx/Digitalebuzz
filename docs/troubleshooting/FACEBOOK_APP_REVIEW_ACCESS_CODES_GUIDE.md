## 🎯 Question: Access Codes/Test Credentials

**Question:**
> "If payment or membership is required to access the full functionality of this app, provide access codes or test credentials so we can access and review all features on this app."

**Requirements:**
- Codes should be active for one year after submission
- If using Facebook Login, can create Facebook test user

## ✅ Important Points

### What to Include:

- ✅ **Free Plan Available** - Mention this first
- ✅ **Test Account Credentials** - Provide if you create one
- ✅ **Sign Up URL** - Where reviewers can create account
- ✅ **Login URL** - Where to log in
- ✅ **Testing Instructions** - Step-by-step guide
- ✅ **Confirmation** - All features available on Free plan

### What NOT to Include:

- ❌ Real user credentials
- ❌ Production admin accounts
- ❌ Accounts with sensitive data
- ❌ Payment information
